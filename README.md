## 🧭 Camino de Ejecución

1. `pnpm install` — Preparar el entorno
2. `pnpm dev` — Lanzar en entorno local (`localhost:3000`)
3. `pnpm build && pnpm export` — Exportar a producción
4. `pnpm run generate:architecture` — Generar docs + gráficas
5. `curl http://localhost:3000/health` — Verificar status de vida
